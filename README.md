## How the site is built

Plain HTML, CSS and JavaScript, with no build step and no dependencies. All text comes from one file,
`js/content.js`, and the pages render from it. Hosted on GitHub Pages.

To run it locally:

```bash
python -m http.server 5173
```

Then open http://localhost:5173.

After changing a CSS or JS file, raise the `?v=` number on its links in the three `.html` files
(for example `?v=2` → `?v=3`), so browsers fetch the new file instead of an old saved copy.
